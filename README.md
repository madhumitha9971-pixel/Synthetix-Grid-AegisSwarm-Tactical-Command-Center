## 📌 Problem Statement
Micro-level urban flash floods and ravine surges escalate faster than traditional manual disaster reporting systems can respond. High-elevation basins lack localized, sub-minute emergency triage mechanisms, leading to delayed evacuation alerts during sudden cloudburst events.

## 🚀 Solution Overview
**Synthetix-Grid (AegisSwarm)** provides micro-second autonomous disaster intelligence by pairing interactive geospatial basin selection with a 3-node LLM consensus matrix:
* **Node Alpha (IoT Telemetry):** Evaluates real-time precipitation inflow and river rise speeds.
* **Node Beta (Topographical Solver):** Computes slope runoff vectors and culvert saturation capacities.
* **Node Gamma (Historical Precedent Index):** Correlates live sensor metrics with historical flash flood recurrence patterns.

When multi-agent consensus exceeds **85% confidence**, the system instantly triggers localized Web Audio emergency sirens and streams live Python routing scripts to crisis response teams.

---

## 🔥 Key Features
- **Interactive Multi-Basin Pinning:** Tap target basin markers (*Sector 4 Alpine*, *Sector 2 Ravine*, *Sector 7 Gorge*) to dynamically update elevation vectors and live sensor parameters.
- **3D Swarm Consensus Matrix:** Visualizes decentralized agent reasoning nodes rendering vector coordinates in real time.
- **Sub-Second Groq LLM Inference:** Powered by standard production endpoints (`llama3-70b-8192`) running multi-agent evaluation traces.
- **Web Audio Oscillators:** Browser-native dual-tone siren sweeping between 600Hz and 950Hz on emergency threshold breaching.
- **Real-Time Audit Terminal:** Monospaced live stream printing Python routing payloads and consensus verification logs.
